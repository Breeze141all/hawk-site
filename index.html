Можливості терміналу

Розроблено для глибокого аналізу ліквідності

2D Liquidation Heatmap

2D сітка Time × Price з бінами ліквідацій ($100 для BTC), відсіканням тінями свічок та підтримкою фірмових колірних тем.

Issue #1 • Implemented

Footprint & Binary Cache

Кластерний аналіз угод з ультрашвидким кешуванням тіків у форматі LZ4 (`.fp.bin`), обмеженням споживання RAM та чесним backfill.

Issue #8 • Implemented

Multi-Period Rolling VWAP

Ковзні вікна 7d, 30d, 90d, 365d та сесійні періоди з динамічними смугами відхилення (1σ, 2σ, 3σ standard deviations).

Issue #2 • Implemented

Market Replay Simulator

Покрокове відтворення історичних торгів, інтерактивний календар вибору дати/часу та режим Random Bar для тренування стратегій.

Issue #4 • Implemented

Розумні алерти цін

Тригери CrossAbove / CrossBelow, аудіо-сигнали, візуальні спливаючі Toasts, бейджі рівнів на ціновій шкалі та централізований менеджер.

Issue #5 • Implemented

Trade Journal & PnL

Вбудований журнал торгівлі з трьома режимами: компактний бічний сайдбар (330px), розширений повноекранний дашборд або вимкнено.
