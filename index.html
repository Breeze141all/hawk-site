FAQ

Electron споживає гігабайти оперативної пам'яті та страждає від пауз збирача сміття (GC stalls), що критично під час спалахів волатильності. Rust + Iced забезпечують нативну продуктивність, мінімальне навантаження на процесор та мікросекундну швидкість оновлення чартів.
Усі ключі API бірж шифруються і зберігаються суто локально у конфігураційній системі вашого комп'ютера. Термінал зв'язується з серверами бірж напряму без жодних проміжних серверів.
Windows 10/11 (x64), macOS (Intel або Apple Silicon M1/M2/M3), або Linux (x86_64). Потрібно від 4 ГБ оперативної пам'яті та стабільне інтернет-з'єднання.
Модуль квантує цінові рівні з кроком у $100 для BTC, моделюючи ліквідаційні пули плечових позицій з відсіканням ціновими тінями свічок за історичний період.
